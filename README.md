# Qmed Scribe Proceedings for Windows

This repository distributes signed Windows x64 installers and automatic updates for Qmed Scribe Proceedings.

Each stable release includes the installer, its matching blockmap and the Windows update manifest. Once you have installed a version that supports automatic updates, use **Help → App updates** to check for a newer version. Finish any recording or edits before choosing **Restart & install update**.

If your installation says that your administrator provides updates, ask your administrator for the first signed installer. Install it under the same Windows account that you use for Proceedings.
