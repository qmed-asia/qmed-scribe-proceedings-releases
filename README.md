# Qmed Scribe Proceedings for Windows

[Download for Windows x64](https://proceedings.qmed.ai/download/windows) · [Installer SHA-256](https://proceedings.qmed.ai/landing/windows-sha256.txt)

For a first installation or an upgrade from 0.8.4 or earlier, finish any recording, quit Proceedings and run the installer under the same Windows account. Compare the downloaded file’s SHA-256 with the checksum on Qmed’s website. Windows can display an unknown publisher because the installer has no public Windows code-signing certificate.

Starting with 0.8.5, open **Help → App updates** to get future releases. The app checks Qmed’s digital signature and the installer hash before installation. Finish any recording or edits, then choose **Restart & install update**.

GitHub hosts the installer, blockmap and signed update manifest for each release. Client PCs can download them without a GitHub account.
